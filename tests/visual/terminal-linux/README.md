# Ordinary Neovim terminal evidence

Actual Linux runs with Neovim 0.13 and no Sprite plugin API on the runtime
path. `foot.png` shows plain text icon tags when the terminal has no graphics
support. `ghostty.png` shows raster icons through the graphics path. Each JSON
records its terminal capability and the visible 11 tree rows, including
dotfiles. These captures predate the final native styling commits; the terminal
renderer and its starter-pack default were unchanged by those styling edits.
